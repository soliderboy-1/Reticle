# Reticle 前端页面结构说明

> 基于 `frontend/src` 实际代码整理（Vue 3 + Vue Router + Pinia）。
> 约定：`View` = 路由页面；`Component` = 可复用区块；`Store` = Pinia 状态。

---

## 0. 全局壳层（所有登录后页面共用）

│  ├─────────────────┤  │                                                │

- 除 `/login`、`/register` 外全部需要登录（`localStorage.access_token`）

## 1. Dashboard 总览　`/`

**布局**

```
┌──────────────────────────────────────────────────────────────┐
│  Eyebrow「Multi-Agent Security Platform」                     │
│  大标题（两行，第二行渐变）                                     │
│  副标题                                                       │
│  [新建检测任务]  [查看历史任务]     LLM 状态 · 重新检测          │
│                                                              │
│        ┌────────────────────────────────────┐                │
│        │ 浮动玻璃卡：累计 / 已完成 / 进行中   │  ← 鼠标视差     │
│        │ 完成度进度条 + 智能体占位            │                │
│        └────────────────────────────────────┘                │
├──────────────────────────────────────────────────────────────┤
│  KPI ①累计任务 ②已完成 ③进行中 ④异常任务（4 张白卡）            │
├───────────────────────────────────┬──────────────────────────┤
│  最近任务（5 条，状态点/进度/跳转） │  检测流程 5 步竖向 stepper │
├───────────────────────────────────┴──────────────────────────┤
│  多智能体能力：检测 / 推理 / 验证 / 报告与修复（4 张 tile）      │
│  页脚                                                         │
└──────────────────────────────────────────────────────────────┘
```

**组件**：`NewTaskDialog`（弹窗）
**功能**
- 新建任务弹窗（上传 `.sol`/`.zip`、选择检测模式）
- 任务统计：累计 / 完成 / 进行中 / 异常
- 最近 5 条任务，点击进入审计详情；运行中显示进度条
- LLM 接入状态展示，可点击重新探测
- 滚动揭示 + Hero 视差交互

**数据**：`auditStore.fetchTasks()`、`llmApi.status()`

## 2. TaskHistory 历史任务　`/tasks`

**布局**

```
┌──────────────────────────────────────────────────────────────┐
│ 历史任务                        [状态下拉][风险等级][日期范围][重置] │
├──────────────────────────────────────────────────────────────┤
│ [已创建 0][排队中 0][检测中 0][已完成 1][失败 0][已取消 0][已中断 0] │ ← 可点击筛选
├──────────────────────────────────────────────────────────────┤
│ 任务 ID │ 状态 │ 风险等级 │ 进度 │ 创建时间 │ 操作              │
│ ────────┼──────┼──────────┼──────┼──────────┼───────────────── │
│ TASK-…  │ 已完成│  高      │ 100% │ 10/28 …  │ 日志 查看报告 重试 │
├──────────────────────────────────────────────────────────────┤
│ 共 N 条记录                                    [上一页][1/1][下一页] │
└──────────────────────────────────────────────────────────────┘
        └── 点击「日志」→ 右侧/弹层展示任务执行日志
```

**组件**：无独立子组件（表格原生实现）+ 日志弹层
**功能**
- 三条件筛选：状态、风险等级、创建日期范围；一键重置
- 状态统计 pill，点击即按该状态过滤
- 分页（前端切片）
- 行操作：查看执行日志、查看报告、复用源码重试（二次确认）
- 风险等级需要逐任务取报告计算，结果缓存（`ensureRiskLevels`）

**数据**：`auditStore.fetchAllTasks()`、`fetchTaskLogs()`、`retryTask()`

## 3. AuditDetail 审计详情　`/audit/:taskId`

**布局**

```
┌──────────────────────────────────────────────────────────────┐
│ 5 张 KPI：输入合约总数 / 正常合约 / 异常合约 / 漏洞发现 / 预警项   │
│ 合约检测结果：每个合约一行（合约名、异常标记、函数数、风险%、发现数）│
├──────────────────────────────────────────────────────────────┤
│ [执行流程] [函数风险排名 TOP 10] [其他潜在风险] [推理路径]        │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ 当前 Tab 内容（表格 / 时间线 / 预警列表 / 推理面板）        │ │
│ └──────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

**组件**：`TopCards`、`TimelinePanel`、`RiskRankingTable`、`RiskWarningList`、`ReasoningPathPanel`
**功能**
- 四种状态分支：
  - 加载中（转圈）
  - 运行中 / 排队中：阶段名 + 百分比 + 取消按钮
  - 失败：错误信息 + 重新检测
  - 成功：结果视图
- 4 个 Tab 切换；`?tab=reasoning` 可深链直达
- 运行中每 3 秒轮询，离开页面自动停止
- 合约级汇总 + 函数级风险表 + 推理路径

**数据**：`fetchTask()`、`fetchReport()`、`startPolling(3s)`、`top10RiskVectors`、`otherWarnings`

## 4. Report 审计报告　`/report/:taskId`

**布局**

```
┌──────────────────────────────────────────────────────────────┐
│ 审计报告 [成功]       任务ID · 模式 · 耗时 · 生成时间   [下载 MD] │
├──────────────────────────────────────────────────────────────┤
│ 7 张统计卡：漏洞总数 / 已验证 / 疑似 / 高 / 中 / 低 / 预警项      │
├──────────────────────────────────────────────────────────────┤
│ 详细报告（Markdown 渲染，marked）                              │
├──────────────────────────────────────────────────────────────┤
│ 检测执行流程（时间线，阶段 + 耗时）                              │
└──────────────────────────────────────────────────────────────┘
```

**组件**：Markdown 渲染（`marked`）+ 时间线（原生）
**功能**
- 元信息总览、7 维发现统计
- JSON 报告 → Markdown 渲染（标题/表格/代码块有专门样式）
- 下载 Markdown 文件
- 打印样式：隐藏侧栏与按钮，适合导出 PDF
- 空态 / 加载态 / 错误态

**数据**：`reportsApi.getReportMarkdown()` + `auditStore.currentTask`

## 5. AgentRuntime 智能体运行　`/agents/:taskId?`

**布局**

```
┌───────────────┬──────────────────────────────────────────────┐
│ 智能体列表 280 │ 选中智能体概要：状态 · 起止时间 · 耗时          │
│ ┌───────────┐ │ ┌────────────┬────────────┐                  │
│ │ 检测       │ │ │ 输入摘要    │ 输出摘要    │                  │
│ │ 推理       │ │ └────────────┴────────────┘                  │
│ │ 验证       │ │ 该智能体对最终报告的贡献（分块展示）            │
│ │ 修复       │ │ 执行日志（时间 / 事件 / 消息 / 详情）           │
│ │ 报告       │ │                                              │
│ └───────────┘ │                                              │
└───────────────┴──────────────────────────────────────────────┘
```

**组件**：无（直接调 `reportsApi.getAgents()`）
**功能**
- 5 类智能体列表：状态徽标、描述、耗时、日志数
- 切换智能体查看详情
- 输入/输出 JSON 预览、报告贡献、逐条执行日志
- 手动刷新

**数据**：`GET /api/v1/audits/{id}/agents`

## 6. CrossContract 跨合约调用图　`/cross-contract`

**布局**

```
┌──────────────────────────────────────────────────────────────┐
│ 跨合约调用图                         当前任务 · [选择审计任务]    │
├──────────────────────────────────────────────────────────────┤
│ 5 张统计：合约节点 / 函数节点 / 调用边 / 风险边 / 跨合约风险发现   │
├───────────────────────────────────────────┬──────────────────┤
│  调用图（可缩放、可拖拽、图例、重置视图）    │ 节点详情面板 288  │
│  节点=合约/函数，边=调用关系，红=风险        │ 类型/风险/R_func  │
│  点击节点高亮；悬停边显示方法名              │ GCN 说明/跳详情   │
└───────────────────────────────────────────┴──────────────────┘
```

**组件**：`CallGraph` + `useCallGraph`（报告 → 图数据）
**功能**
- 合约/函数节点、调用边、风险边可视化
- 缩放/拖拽/重置视图
- 点击节点查看详情（类型、风险等级、R_func、跨合约发现数）
- 悬停边显示方法名
- 无报告时引导去选择任务

## 组件使用矩阵

| 组件 | 被谁使用 | 作用 |
|---|---|---|
| `layout/Sidebar.vue` | MainLayout | 导航、当前任务、新建任务入口 |
| `layout/Header.vue` | MainLayout | 面包屑、模型状态、用户菜单 |
| `dashboard/NewTaskDialog.vue` | Sidebar、Dashboard | 上传合约 + 选模式 + 提交 |
| `dashboard/TopCards.vue` | AuditDetail | 5 张 KPI + 合约清单 |
| `analytics/TimelinePanel.vue` | AuditDetail | 执行流程时间线 |
| `analytics/RiskRankingTable.vue` | AuditDetail | 风险 TOP 10 表 |
| `analytics/RiskWarningList.vue` | AuditDetail | 其他潜在风险 |
| `panels/ReasoningPathPanel.vue` | AuditDetail | 推理路径 |
| `dashboard/CallGraph.vue` | CrossContract | 调用图可视化 |
| `dashboard/FunctionRiskRanking.vue` | FunctionRiskRanking | 全量风险表 |
| `dashboard/RepairSuggestions.vue` | RepairSuggestions | 修复建议卡 + 补丁 Diff |
| `editor/MonacoCodeViewer.vue` | RepairSuggestions | 代码查看 |
| `editor/MonacoDiffEditor.vue` | RepairSuggestions | 补丁前后对比 |
| `analytics/RadarChart.vue` | **未被引用** | 预留雷达图 |
| `editor/CodeEditor.vue` | **未被引用** | 预留编辑器 |
| `panels/FindingDetailPanel.vue` | **未被引用** | 预留发现详情 |

> 说明：`RadarChart`、`CodeEditor`、`FindingDetailPanel` 目前没有任何页面 import，属于未接线的预留组件。
